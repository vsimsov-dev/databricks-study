Day 17 · MLflow

MLflow 기초

실험 추적과 모델 관리의 표준 도구

⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제 🔄 복습: 4문제
오늘의 핵심 개념

물성 예측 모델을 하나 만들어보면 금방 알게 됩니다. 배합비를 바꾸고, 학습 데이터를 바꾸고, 알고리즘 파라미터를 바꾸면서 수십 번 실험을 반복하다 보면 "어제 정확도가 제일 높았던 조합이 뭐였지?"라는 질문에 답하기가 의외로 어렵습니다. 노트북 셀을 다시 실행해봐도 결과가 조금씩 달라지고, 어떤 코드로 어떤 결과를 냈는지 기억이 뒤섞입니다.

MLflow는 이 문제를 해결하기 위해 만들어진 오픈소스 플랫폼입니다. 모델을 학습할 때마다 사용한 조건(파라미터)과 결과(성능 지표), 심지어 모델 파일 자체까지 자동으로 기록해두어, 나중에 "그때 그 실험"을 정확히 다시 찾아볼 수 있게 해줍니다. Databricks에는 MLflow가 기본 내장되어 있어 별도 설치 없이 바로 쓸 수 있습니다.

🧪 MLflow란? — "실험 노트를 대신 써주는 조수"

연구실에서 배합 실험을 할 때 조건과 결과를 실험 노트에 손으로 기록하듯, 모델 개발도 똑같은 기록이 필요합니다. 다만 모델 실험은 몇 번이 아니라 수십, 수백 번 반복되기 때문에 손으로 기록하다 보면 누락되거나 뒤섞이기 쉽습니다. MLflow는 코드 실행 한 번마다 조건과 결과를 자동으로 남겨주는 디지털 실험 노트 역할을 합니다.

❌ MLflow 없이
엑셀에 파라미터와 정확도를 손으로 옮겨 적다가 몇 번 놓치고, 어떤 모델 파일이 어떤 실험 결과였는지 헷갈림
✅ MLflow 사용 시
코드 실행마다 파라미터·정확도·모델 파일이 자동 기록되어, 실험 목록에서 클릭 한 번으로 비교·재현 가능

📊 Tracking — 실험을 자동으로 기록하기

MLflow의 가장 기본 기능은 Tracking(추적)입니다. 모델을 학습시키는 코드에 몇 줄만 추가하면, 학습에 사용한 하이퍼파라미터(예: 학습률, 반복 횟수)와 결과 지표(예: 정확도, 오차율)가 자동으로 기록되고, 웹 화면에서 실험들을 표로 나란히 비교할 수 있습니다.

# MLflow Tracking 기본 예시 import mlflow with mlflow.start_run(): mlflow.log_param("압출_온도", 230) mlflow.log_param("스크류_속도", 150) mlflow.log_metric("인장강도_예측_오차", 1.8) mlflow.sklearn.log_model(model, "pp_강도_예측모델")

🗂️ Model Registry — 모델의 버전을 관리하는 저장소

실험을 반복하다 보면 "쓸 만한" 모델이 여러 개 나옵니다. Model Registry(모델 레지스트리)는 이런 모델들을 이름과 버전으로 정리해 보관하는 저장소입니다. v1, v2, v3처럼 버전을 매기고, 어떤 버전이 현재 운영 중인지(Production), 어떤 버전이 테스트 중인지(Staging)를 태그로 관리할 수 있습니다. 새 버전 모델의 성능이 더 좋다고 확인되면 운영 버전을 안전하게 교체할 수 있습니다.

MLflow 모델 관리 흐름
실험 반복 (Tracking)
→
모델 등록 (Registry)
→
버전 승격 (Staging→Production)
→
배포·서빙

실험부터 운영 배포까지 전 과정을 한 플랫폼에서 추적합니다

🔁 재현성(Reproducibility) — 왜 이렇게까지 기록해야 할까?

모델이 예상과 다르게 동작하거나, 몇 달 전 만든 모델을 다시 검토해야 할 때 "그때 정확히 어떤 데이터와 조건으로 학습했는가"를 재현할 수 있어야 합니다. MLflow는 코드 버전, 데이터, 파라미터, 환경 정보까지 함께 기록하기 때문에, 시간이 지나도 동일한 실험을 다시 실행하고 결과를 검증할 수 있습니다. 이는 품질 문제가 생겼을 때 원인을 추적하는 데도 그대로 적용되는 사고방식입니다.

구분MLflow TrackingModel Registry
목적실험 조건·결과 기록 및 비교완성된 모델의 버전·배포 상태 관리
주요 대상파라미터, 지표, 학습 코드모델 파일, 버전 번호, 운영 단계
비유실험 노트완제품 창고 대장

🧪 고분자제품기술팀에서의 활용 예시

팀에서는 배합비·압출 조건과 인장강도·열접착강도 같은 물성 데이터를 축적해 예측 모델을 만들 때 MLflow Tracking을 활용할 수 있습니다. 스크류 속도, 온도, 원료 배합비 조합을 바꿔가며 수십 번 학습을 반복해도, 어떤 조합이 오차를 가장 줄였는지 표로 한눈에 비교할 수 있습니다. 신뢰도가 검증된 모델은 Model Registry에 등록해 현장 품질관리팀이 실제 물성 예측에 사용하는 운영 버전으로 승격시키고, 새 데이터가 쌓여 더 정확한 모델이 나오면 버전을 교체하는 방식으로 운영할 수 있습니다.

💡 실무 적용 아이디어

CPP·투명 PP 물성 예측이나 압출코팅 공정 최적화 모델을 개발할 때, 실험마다 조건과 결과를 MLflow로 자동 기록해두면 "가장 좋았던 조건"을 나중에 다시 찾느라 시간을 허비하지 않아도 됩니다.

🔑 핵심 용어 카드

MLflow
머신러닝 실험 추적부터 모델 등록·배포까지 전체 생애주기를 관리하는 오픈소스 플랫폼. Databricks에 기본 내장됨.
Tracking
모델 학습마다 파라미터·지표·결과물을 자동으로 기록하고 비교할 수 있게 해주는 MLflow의 핵심 기능.
Run
모델 학습을 한 번 실행한 단위. 각 Run마다 파라미터와 결과가 별도로 기록됩니다.
Model Registry
완성된 모델을 이름과 버전으로 등록·관리하고, Staging·Production 같은 배포 단계를 관리하는 저장소.
재현성 (Reproducibility)
동일한 조건으로 실험을 다시 실행했을 때 같은 결과를 재현할 수 있는 성질. 모델 신뢰성의 핵심 요건.
📌 한 줄 요약

MLflow는 반복되는 모델 실험의 조건과 결과를 자동으로 기록하고, 검증된 모델을 버전별로 관리해 운영에 안전하게 배포할 수 있게 해주는 표준 도구입니다.

오늘의 퀴즈 — 5문제
1MLflow에 대한 설명으로 가장 알맞은 것은?
✅ 정답: ③ — MLflow는 모델 실험의 조건과 결과를 기록(Tracking)하고, 완성된 모델을 버전별로 관리·배포(Model Registry)하는 것까지 지원하는 오픈소스 플랫폼이며, Databricks에 기본 내장되어 있습니다.
2MLflow Tracking 기능이 자동으로 기록해주는 것으로 가장 알맞은 것은?
✅ 정답: ② — Tracking은 모델을 학습할 때마다 사용한 하이퍼파라미터와 결과 지표를 자동 기록해, 여러 실험을 표로 비교할 수 있게 해줍니다.
3Model Registry의 역할로 가장 알맞은 것은?
✅ 정답: ① — Model Registry는 검증된 모델을 버전별로 등록·보관하고, 어떤 버전이 운영 중인지(Production) 관리하는 저장소 역할을 합니다.
4모델 개발에서 "재현성(Reproducibility)"이 중요한 이유로 가장 알맞은 것은?
✅ 정답: ④ — 시간이 지난 뒤에도 같은 조건으로 실험을 재현할 수 있어야 모델이 예상과 다르게 동작할 때 원인을 정확히 추적하고 검증할 수 있습니다.
5고분자제품기술팀 업무에서 MLflow를 활용하기 가장 적절한 예시는?
✅ 정답: ② — MLflow는 반복되는 물성 예측 모델 실험의 조건·결과를 자동 기록하고, 검증된 모델을 버전별로 관리해 현장에 안전하게 배포하는 데 활용할 수 있습니다.
🔄 어제 배운 내용 복습 — 프롬프트 엔지니어링 기초
1프롬프트 엔지니어링에 대한 설명으로 가장 알맞은 것은?
✅ 정답: ③ — 프롬프트 엔지니어링은 AI 모델 자체를 바꾸는 것이 아니라, 원하는 결과를 얻기 위해 질문·지시문을 효과적으로 설계하는 방법입니다.
2Few-shot Prompting이란 무엇인가요?
✅ 정답: ① — Few-shot Prompting은 원하는 출력 형식이나 패턴의 예시를 함께 제시해, AI가 그 예시를 참고해 답변을 생성하도록 유도하는 기법입니다.
3"단계별로 생각해봐(Let's think step by step)"라는 문구를 프롬프트에 추가하는 기법의 이름과 효과는?
✅ 정답: ③ — Chain-of-Thought 기법으로, AI가 결론을 바로 내지 않고 중간 추론 과정을 거치도록 유도해 복잡한 문제의 답변 정확도를 높입니다.
4고분자제품기술팀 업무에서 프롬프트 설계를 가장 잘 적용한 예시는?
✅ 정답: ② — 역할 부여, 맥락(기준치), 구체적 지시, 출력 형식을 함께 제시하면 AI 답변의 일관성과 정확도가 높아져 실무 활용도가 커집니다.
