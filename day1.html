Day 1 — Databricks와 레이크하우스

데이터 창고와 저수지를 합친 새로운 패러다임

📅 2026년 6월 12일 ⏱ 약 15분 🎯 초급 ✏️ 퀴즈 5문제
오늘의 개념

🤔 왜 이 개념이 필요할까요?

고분자제품기술팀에서 매일 다루는 데이터를 생각해봐요. PP·PE·EAA 필름의 두께, 인장강도, 투명도 같은 숫자 데이터가 있는가 하면, 불량 사진, 검사 보고서 PDF, 시험 성적서 같은 자료도 있죠. 지금은 이게 엑셀 파일, 공유 드라이브, ERP 시스템에 뿔뿔이 흩어져 있을 거예요. "이 데이터들을 한 곳에서 관리하고, AI까지 연결하려면 어떻게 해야 할까?" — 이 질문에 대한 답이 바로 오늘의 주제입니다.

🏛️ 전통적인 방식 — 데이터 웨어하우스

2000년대부터 많은 기업이 사용해온 방식이에요. 쉽게 말하면 아주 잘 정리된 창고예요. 창고에 물건을 넣으려면 반드시 정해진 박스(형식)에 담아야 해요. 두께: 0.05mm, 강도: 120MPa처럼 칸이 딱 정해져 있고, 그 칸에 맞는 숫자나 텍스트만 넣을 수 있어요.

덕분에 조회 속도가 매우 빠르고 데이터가 깔끔하게 유지돼요. 하지만 단점도 명확해요. 불량품 사진 파일이나 안전 교육 영상은 넣을 수가 없어요. 그리고 데이터가 엄청나게 쌓일수록 비용이 기하급수적으로 올라가요. 대기업 기준으로 연간 수십억 원이 드는 경우도 흔해요.

💧 그래서 나온 것 — 데이터 레이크

웨어하우스의 단점을 극복하기 위해 2010년대에 등장했어요. 이름 그대로 거대한 저수지예요. 형식 상관없이 모든 데이터를 다 받아요. 엑셀 파일, PDF, 사진, 동영상, 센서 로그... 다 OK예요. 저장 비용도 웨어하우스의 10분의 1 이하예요.

그런데 현실에서 문제가 생겼어요. 뭐든 다 던져 넣다 보니 어디에 뭐가 있는지 아무도 몰라요. "이 파일이 맞는 버전이야?" "이 데이터 믿을 수 있어?" 이런 질문에 아무도 답 못 하는 상황이 생기는 거예요. 업계에서는 이걸 데이터 늪(Data Swamp)이라고 불러요.

Hadoop, S3

  • ✅ 합리적인 비용
  • ✅ AI와 바로 연결
Databricks ✨

🏠 Databricks의 해법 — 레이크하우스 + Delta Lake

Databricks는 2013년 UC Berkeley 연구팀이 창업한 회사예요. 이들이 내놓은 답은 레이크하우스(Lakehouse)예요. 핵심 기술은 Delta Lake라는 데이터 저장 포맷인데, 데이터를 넣은 후에도 수정·삭제가 자유롭고, 모든 변경 이력이 자동으로 기록돼요. 마치 Google 문서처럼 "5분 전 버전으로 되돌리기"가 가능한 거예요. 오픈소스라 특정 회사에 종속되지도 않아요.

💡 Delta Lake를 엑셀로 비유하면? 일반 데이터베이스가 "저장 후 수정 불가한 잠긴 엑셀"이라면, Delta Lake는 "자동 저장 + 버전 히스토리 + 동시 편집"이 되는 스마트한 공유 엑셀이에요. 여러 사람이 동시에 접근해도 충돌 없이 안전하게 작동해요.

🏭 고분자제품기술팀 업무에서는 이렇게 쓸 수 있어요

📊

제품 품질 데이터 통합

PP·PE·EAA 필름의 두께·강도·투명도 측정값(정형)과 불량 사진·검사 보고서(비정형)를 한 플랫폼에서 관리. 수치와 이미지를 연결해 불량 원인 분석 자동화 가능.

🔬

신제품 개발 데이터 축적

고분자 제품 개발 과정의 배합 레시피, 실험 데이터, 시험 성적서를 통합 관리. 과거 개발 이력 기반으로 AI가 최적 배합 조건 예측 가능.

🤝

기술지원 이력 관리

고객사별 기술지원 요청·처리 기록(정형)과 테스트 보고서·제안서 문서(비정형)를 통합. AI로 유사 이슈 검색 및 대응 방안 자동 제안 가능.

⚗️

소재 물성 데이터베이스

PP·PE·EAA 각 그레이드별 물성 데이터를 통합 저장. 고객 요구 스펙에 맞는 최적 소재를 AI가 자동 추천하는 시스템 구축 가능.

📖 오늘의 핵심 용어

데이터 웨어하우스

정형 데이터만 저장하는 고성능 저장소. 빠르지만 비싸고 유연하지 않음.

데이터 레이크

모든 형식의 데이터를 저렴하게 저장. 유연하지만 관리가 어려움.

레이크하우스

레이크 + 웨어하우스의 장점을 결합. Databricks가 선도하는 최신 패러다임.

Delta Lake

레이크하우스를 구현하는 오픈소스 저장 포맷. 수정·삭제·버전 관리 지원.

정형 데이터

행과 열로 정리된 데이터. 숫자, 날짜, 코드값 등. 엑셀이 대표적.

비정형 데이터

정해진 형식이 없는 데이터. 사진, 영상, PDF, 텍스트 문서 등.

오늘의 핵심 요약

Databricks는 레이크하우스라는 개념으로
"모든 데이터를 한 곳에, 빠르고 스마트하게"를 실현합니다.
정형·비정형 구분 없이 저장하고, AI까지 바로 연결되는
차세대 데이터 플랫폼이에요.

오늘의 퀴즈 — 5문제
1데이터 웨어하우스의 특징으로 맞는 것은?
✅ 정답: ②웨어하우스는 정형 데이터 특화, 빠른 조회가 강점이에요. 대신 비용이 높고 비정형 데이터(사진, PDF 등)는 저장할 수 없어요.
2데이터 레이크가 "데이터 늪(Data Swamp)"이 됐다고 표현하는 이유는?
✅ 정답: ③뭐든 다 넣을 수 있다는 게 장점이지만, 관리 체계 없이 쌓이면 어디에 뭐가 있는지 아무도 모르는 늪이 돼버려요.
3레이크하우스(Lakehouse)를 가장 잘 표현한 것은?
✅ 정답: ②레이크(유연성·저비용) + 웨어하우스(속도·관리)의 장점을 합쳐 단점을 최소화한 구조예요.
4Delta Lake의 특징이 아닌 것은?
✅ 정답: ④Delta Lake는 정형·비정형 데이터를 모두 지원해요. ①②③은 모두 실제 특징입니다.
5고분자 제품 개발 업무에서 레이크하우스가 유용한 이유는?
✅ 정답: ②레이크하우스는 정형·비정형 데이터를 모두 저장하고 AI까지 바로 연결할 수 있어, 고분자 제품 개발·기술지원 업무 데이터 통합에 최적화돼 있어요.
