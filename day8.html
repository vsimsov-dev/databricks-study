메달리온 아키텍처

Bronze → Silver → Gold, 단계별 데이터 품질 향상의 비법

📅 2026년 6월 18일 ⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제
개념 설명

왜 데이터를 계층으로 나누나?

원시 데이터를 그대로 분석에 사용하면 문제가 생깁니다. 중복된 행, 잘못 입력된 값, 형식이 맞지 않는 날짜… 이런 데이터로 만든 대시보드나 ML 모델은 신뢰하기 어렵습니다. 그렇다고 원시 데이터를 바로 지워버리면 나중에 문제가 생겼을 때 추적이 불가능합니다.

메달리온 아키텍처(Medallion Architecture)는 이 문제를 해결하기 위해 데이터를 3개의 레이어로 나눠 관리하는 설계 패턴입니다. 원시 데이터는 그대로 보존하면서, 단계적으로 품질을 높여 분석에 적합한 형태로 만들어갑니다.

LAYER 1

🥉 Bronze

원시 데이터 그대로 보존
  • 소스에서 수집한 원본 데이터
  • 변환 없이 있는 그대로 저장
  • 오류·중복 데이터도 포함
  • 데이터 손실 없는 안전망 역할
→
LAYER 2

🥈 Silver

정제·검증된 데이터
  • 중복 제거, 이상값 처리
  • 스키마 통일 및 타입 변환
  • NULL 값 처리 및 검증
  • 여러 소스 데이터 통합(JOIN)
→
LAYER 3

🥇 Gold

분석·보고용 집계 데이터
  • 비즈니스 로직 적용
  • 그레이드별·기간별 집계
  • BI 대시보드·ML용 피처
  • 최고 품질의 신뢰 데이터

각 레이어의 역할

Bronze 레이어는 "데이터의 원본 보존소"입니다. 소스 시스템에서 데이터를 가져와 아무런 변환 없이 그대로 저장합니다. 나중에 처리 로직에 버그가 있었다는 걸 발견해도 항상 원본으로 돌아가 재처리할 수 있습니다.

Silver 레이어는 "데이터 세탁소"입니다. Bronze 데이터를 읽어 중복을 제거하고, 이상값을 처리하며, 컬럼 형식을 통일합니다. 여러 테이블을 JOIN해 하나의 넓은 테이블(wide table)로 만들기도 합니다. 이 레이어부터는 데이터 품질 기준을 통과한 신뢰할 수 있는 데이터가 됩니다.

Gold 레이어는 "분석용 완제품"입니다. Silver 데이터에 비즈니스 로직을 적용해 BI 대시보드, 리포트, ML 피처 스토어에 바로 사용할 수 있는 형태로 집계합니다. 최종 사용자가 실제로 소비하는 데이터입니다.

고분자팀 관점에서 보면?

🏭 고분자제품기술팀 메달리온 아키텍처 적용 예시
🥉 Bronze ERP에서 추출한 원시 생산 데이터, 측정 장비의 원시 CSV 파일 — 입력 오류·중복 행 포함 그대로 저장
🥈 Silver 이상값 제거(물리적으로 불가능한 수치 필터링), 중복 제거, 컬럼명 통일, PP/PE/EAA 제품 코드 정규화, 측정일 형식 통일
🥇 Gold 그레이드별 월평균 인장강도·신율·헤이즈 집계 테이블, 고객사별 납품 물성 이력 요약, BI 대시보드용 KPI 집계

메달리온 아키텍처의 핵심 장점

🔄

재처리 가능성

Bronze에 원본이 항상 보존되므로 Silver/Gold 로직에 오류가 생겨도 처음부터 다시 처리할 수 있습니다.

📈

단계적 품질 향상

레이어를 거칠수록 데이터 품질이 높아집니다. 각 레이어에서 품질 검증 규칙을 적용할 수 있습니다.

🔍

투명한 데이터 계보

어떤 원본 데이터가 어떤 변환을 거쳐 최종 결과가 됐는지 추적할 수 있어 감사·규정 준수에 유리합니다.

👥

팀별 역할 분담

데이터 엔지니어는 Bronze·Silver를, 데이터 분석가는 Gold를 주로 다루어 역할이 명확히 나뉩니다.

핵심 용어 카드

메달리온 아키텍처

소스에서 수집한 원시 데이터를 변환 없이 그대로 보존하는 레이어

중복 제거, 이상값 처리, 스키마 통일 등 정제 작업이 적용된 레이어

비즈니스 로직·집계가 적용되어 BI·ML에 바로 사용 가능한 최종 레이어
데이터 계보
데이터가 어디서 와서 어떤 변환을 거쳤는지 추적하는 정보(Data Lineage)

오늘의 퀴즈
1메달리온 아키텍처에서 Bronze 레이어의 역할로 가장 올바른 것은?
✅ 정답: ②
Bronze 레이어는 소스 데이터의 원본 보존소입니다. 오류나 중복이 있어도 그대로 저장합니다. 덕분에 Silver/Gold 레이어에서 오류가 발생해도 Bronze부터 다시 처리할 수 있습니다.
2고분자팀에서 PP 필름 물성 데이터의 이상값(물리적으로 불가능한 수치)을 필터링하고 컬럼명을 통일하는 작업은 어느 레이어에서 수행하나요?
✅ 정답: ③
Silver 레이어는 데이터 정제 단계입니다. 이상값 제거, 중복 삭제, 컬럼명 통일, 타입 변환 등이 이 레이어에서 이루어집니다. Bronze는 원본 보존, Gold는 집계·분석 단계입니다.
3메달리온 아키텍처의 핵심 장점 중 하나는 Bronze 레이어에 원본이 보존된다는 것입니다. 이로 인해 얻을 수 있는 이점은?
✅ 정답: ①
Bronze에 원본이 항상 있기 때문에 Silver나 Gold 처리에 버그가 있었다는 것을 나중에 발견해도 원본부터 다시 처리(재처리)할 수 있습니다. 이것이 메달리온 아키텍처의 핵심 안전망입니다.
4다음 중 Gold 레이어의 데이터 활용 목적으로 가장 적합하지 않은 것은?
✅ 정답: ④
원시 데이터 아카이브는 Bronze 레이어의 역할입니다. Gold 레이어는 비즈니스 로직이 적용된 집계·요약 데이터로 BI, 리포트, ML에 바로 활용하는 목적으로 사용됩니다.
5메달리온 아키텍처에서 레이어가 올라갈수록(Bronze → Gold) 어떤 방향으로 변화하나요?
✅ 정답: ②
Bronze → Silver → Gold로 올라갈수록 데이터 품질·신뢰도·비즈니스 가치가 높아집니다. Gold 레이어의 데이터는 최종 사용자(분석가, 경영진)가 직접 소비할 수 있는 형태입니다.
