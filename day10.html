AI/ML 기초 — LLM과 파운데이션 모델

거대언어모델의 작동 원리

⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제 🔄 복습: 4문제
오늘의 개념

LLM이란 무엇이고, 어떻게 작동하는가?

요즘 어딜 가도 "AI", "ChatGPT", "LLM"이라는 말이 들립니다. 업무에서도 AI를 활용하라는 말을 자주 듣지만, 정작 "이게 어떻게 작동하는 거지?" 라는 의문이 해결되지 않으면 제대로 활용하기 어렵습니다. 오늘은 LLM의 핵심 원리를 이해해봅시다.

Databricks는 단순한 데이터 플랫폼을 넘어, 기업이 자체 AI 모델을 학습시키고 운영할 수 있는 AI 플랫폼으로 진화하고 있습니다. LLM을 이해하면 Databricks의 AI 기능들—Genie, DBRX, Model Serving—이 왜 강력한지 체감할 수 있습니다.

🤖 LLM이란? (Large Language Model)

LLM은 수천억 개의 매개변수(파라미터)를 가진 초대형 신경망 모델로, 방대한 텍스트 데이터를 학습해 자연어를 이해하고 생성합니다. GPT-4, Claude, Gemini, DBRX가 모두 LLM입니다.

💡 비유
PP 원료를 배합할 때, 수천 번의 실험 데이터를 쌓아 "이 조건에서는 이 물성이 나온다"는 패턴을 익히듯, LLM도 수조 개의 문장을 학습해 "이 문맥 다음엔 이 단어가 온다"는 패턴을 익힙니다. 단지 그 규모가 어마어마하게 클 뿐입니다.

🔤 토큰(Token): LLM이 보는 언어의 단위

LLM은 글자나 단어 그대로가 아니라 토큰이라는 단위로 텍스트를 처리합니다. 토큰은 대략 단어의 일부 또는 단어 하나에 해당합니다.

문장 → 토큰화 과정

"고분자 필름의 투명도를 높이려면?"
고분자 필름 의 투명 도 를 높이 려면 ?
각 조각이 하나의 '토큰' — LLM은 이 토큰들의 패턴을 학습

⚙️ Transformer: LLM의 핵심 엔진

현대 LLM은 모두 Transformer 아키텍처 기반입니다. 핵심 원리는 Attention(주의 집중)입니다 — 문장 내 모든 단어가 서로를 얼마나 "주목"해야 하는지를 계산합니다.

🏛️ 파운데이션 모델(Foundation Model)이란?

파운데이션 모델은 범용 목적으로 대규모 학습된 기반 모델입니다. 처음부터 특정 목적으로 만든 것이 아니라, 광범위한 데이터로 학습한 뒤 다양한 용도로 활용(Fine-tuning)할 수 있습니다.

🔧 학습 → 파인튜닝 → 서빙: 모델 생애주기

1
사전 학습 (Pre-training) 인터넷, 책, 논문 등 수조 개의 토큰으로 범용 언어 능력 학습. 엄청난 GPU와 비용이 필요 (수백억 원 규모).
2
파인튜닝 (Fine-tuning) 기업 데이터나 특정 도메인으로 추가 학습. Databricks에서 자체 데이터로 PP 물성 예측 모델을 만든다면 이 단계.
3
RLHF (인간 피드백 강화학습) 사람이 좋은 답변과 나쁜 답변을 채점해 모델을 더 유용하게 조정. ChatGPT가 친절한 이유.
4
서빙 (Model Serving) 학습된 모델을 API로 배포해 실제 서비스에서 사용. Databricks Model Serving이 이를 담당.

🏭 고분자 제품 개발 업무에서는?

📌 팀에서 LLM을 이런 방식으로 활용할 수 있어요
  • 기술 문서 요약: PP/PE 물성 데이터 시트, 고객 클레임 보고서를 LLM으로 자동 요약
  • 실험 조건 제안: 레트로트 내열성 개선 실험 설계 시 LLM에게 초안 제안 요청
  • 화학물질 안전 교육 자료: MSDS 내용을 LLM이 쉬운 언어로 재구성해 안전 교육 자료 생성
  • 파인튜닝 활용: 자사 품질 데이터로 파인튜닝하면 "이 배합에서 OIT는?" 같은 전문 질의에 더 정확하게 답변

📊 기존 AI vs LLM: 무엇이 다른가?

구분 기존 머신러닝 LLM (파운데이션 모델)
학습 방식 특정 문제용 데이터로 학습 방대한 범용 데이터로 학습
활용 범위 한 가지 task (분류/회귀) 질의응답·요약·코딩·번역 등 다목적
커스터마이즈 처음부터 재학습 필요 파인튜닝 또는 프롬프트로 조정
규모 수백만 파라미터 수십억~수천억 파라미터
PP 물성 예측 예시 배합 조건 → MFR 예측 모델 배합 조건 설명 → 종합 분석 + 제안

🗝️ 핵심 용어 정리

LLM
Large Language Model. 수십억~수천억 파라미터를 가진 초대형 언어 모델.
토큰 (Token)
LLM이 처리하는 텍스트의 최소 단위. 단어의 일부~단어 수 개에 해당.
파운데이션 모델
범용 대규모 학습 후 다양한 용도로 활용 가능한 기반 모델.
파인튜닝 (Fine-tuning)
파운데이션 모델을 특정 도메인 데이터로 추가 학습해 전문화하는 과정.
Transformer
현대 LLM의 핵심 아키텍처. Attention 메커니즘으로 문맥을 이해.
💡 한 줄 요약

LLM은 수조 개의 텍스트를 학습해 언어 패턴을 익힌 범용 AI로, Databricks에서 기업 데이터로 파인튜닝하면 고분자 업무에 특화된 AI 어시스턴트를 만들 수 있습니다.

오늘의 퀴즈 — 5문제
1LLM에서 '파라미터(매개변수)'가 많을수록 일반적으로 의미하는 것은?
✅ 정답: ③ — 파라미터는 모델이 학습을 통해 조정하는 가중치의 개수입니다. 파라미터가 많을수록 더 복잡하고 미묘한 언어 패턴을 학습할 수 있지만, 추론 속도는 오히려 느려지고 학습 데이터도 더 많이 필요합니다.
2LLM이 텍스트를 처리하는 기본 단위를 무엇이라 하는가?
✅ 정답: ② — LLM은 텍스트를 '토큰' 단위로 분할해 처리합니다. 토큰은 글자 조각, 단어, 또는 단어 몇 개에 해당하며, LLM은 이전 토큰들을 보고 다음 토큰을 예측하는 방식으로 텍스트를 생성합니다.
3Databricks가 직접 개발한 오픈소스 LLM의 이름은?
✅ 정답: ① — DBRX는 Databricks가 2024년에 공개한 오픈소스 LLM으로, 당시 오픈소스 모델 중 최고 성능을 기록했습니다. Databricks 플랫폼에서 직접 활용하거나 파인튜닝할 수 있습니다.
4파운데이션 모델을 특정 도메인(예: 고분자 물성 분야)에 맞게 추가 학습하는 과정은?
✅ 정답: ④ — 파인튜닝은 이미 범용 학습이 완료된 파운데이션 모델에 특정 도메인 데이터를 추가 학습시켜 전문화하는 과정입니다. 예: PP 물성 데이터로 파인튜닝 → 배합 조건 질의에 특화된 모델 완성.
5현대 LLM 대부분이 기반으로 하는 핵심 아키텍처는?
✅ 정답: ③ — 2017년 Google이 발표한 Transformer 아키텍처는 'Attention is All You Need' 논문에서 시작됐습니다. Self-Attention 메커니즘을 통해 문장 내 모든 단어 간의 관계를 병렬로 처리해, 이전 RNN 방식보다 훨씬 효과적입니다.
🔄 어제 배운 내용 복습 — 데이터 파이프라인 기초
1ETL에서 'T'가 의미하는 단계는?
✅ 정답: ② — ETL은 Extract(추출) → Transform(변환) → Load(적재)의 약자입니다. 변환 단계에서 데이터 정제, 형식 통일, 결측값 처리 등을 수행한 뒤 최종 목적지에 적재합니다.
2ELT가 ETL과 다른 핵심 차이점은?
✅ 정답: ① — ELT(Extract-Load-Transform)는 원시 데이터를 그대로 먼저 레이크하우스에 적재한 뒤, 강력한 컴퓨팅 엔진으로 변환합니다. Databricks처럼 처리 능력이 뛰어난 플랫폼에서 선호되는 방식입니다.
3Databricks Workflows의 주요 역할은?
✅ 정답: ④ — Databricks Workflows는 노트북, SQL, Python 스크립트 등 여러 작업을 순서나 의존관계에 따라 자동으로 실행하는 오케스트레이션 도구입니다. 매일 정해진 시간에 데이터 파이프라인을 자동으로 돌리는 데 활용합니다.
4메달리온 아키텍처에서 '정제된 비즈니스 로직이 적용된 데이터'는 어느 계층에 해당하는가?
✅ 정답: ③ — Gold 계층은 비즈니스 목적에 맞게 최종 집계·가공된 데이터를 담습니다. 예: 월별 PP 제품 불량률 대시보드용 집계 테이블. Silver가 정제된 원시 데이터라면, Gold는 분석·보고에 바로 쓸 수 있는 완성형 데이터입니다.
