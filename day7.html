데이터 타입: 정형·반정형·비정형

데이터의 세 가지 얼굴과 Databricks에서 다루는 법

📅 2026년 6월 17일 ⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제
개념 설명

데이터에도 종류가 있다

우리가 다루는 데이터는 생긴 모양에 따라 크게 세 가지로 나뉩니다. 정형 데이터(Structured), 반정형 데이터(Semi-structured), 비정형 데이터(Unstructured)입니다. 어떤 종류의 데이터인지를 먼저 파악해야 저장 방법, 처리 방법, 분석 방법이 달라지기 때문에 이 구분은 매우 중요합니다.

📊

정형 데이터

행(Row)과 열(Column)로 구성된 표 형식. 스키마가 미리 정해져 있고, SQL로 바로 조회할 수 있습니다.

CSV, DB 테이블, Excel
🗂️

반정형 데이터

구조가 있지만 고정된 스키마는 없습니다. 키-값 쌍이나 계층 구조를 가지며 유연하게 변할 수 있습니다.

JSON, XML, YAML, 로그 파일
🖼️

비정형 데이터

정해진 구조가 없습니다. 텍스트, 이미지, 동영상, 오디오 등이 해당하며 전체 데이터의 80% 이상을 차지합니다.

이미지, PDF, 동영상, 이메일

정형 데이터 — 표 형식, 바로 분석 가능

정형 데이터는 가장 다루기 쉬운 데이터입니다. 행과 열이 정확하게 구분되어 있어 SQL로 바로 조회·분석할 수 있습니다. 데이터베이스 테이블이 대표적인 예이며, 엑셀 파일이나 CSV도 이에 해당합니다. 스키마(어떤 컬럼이 어떤 타입으로 존재하는가)가 미리 고정되어 있어 데이터 품질 관리가 쉽습니다.

Databricks에서는 Delta 테이블로 저장하고 Spark SQL이나 Python DataFrame으로 쉽게 처리할 수 있습니다.

반정형 데이터 — 구조는 있지만 유연하다

반정형 데이터는 완전히 고정된 스키마는 없지만 자체적인 구조 정보를 갖고 있습니다. JSON이 대표적인 예로, 키-값 쌍으로 이루어져 있고 중첩 구조도 가능합니다. 항목마다 포함된 필드가 다를 수 있어 유연성이 높습니다.

💡 JSON 예시 — 시험 성적서 { "lot_id": "PP-2026-0617", "product": "CPP 필름", "tests": [ {"name": "인장강도", "value": 135, "unit": "MPa"}, {"name": "신율", "value": 420, "unit": "%"} ] }

Databricks에서는 from_json() 함수나 AUTO LOADER를 사용해 JSON·XML 파일을 자동으로 파싱하고 Delta 테이블로 변환할 수 있습니다.

비정형 데이터 — 구조가 없는 대다수의 데이터

세상에 존재하는 데이터의 80% 이상은 비정형 데이터입니다. 이미지, 동영상, PDF, 이메일 본문, 소셜 미디어 게시물 등이 해당합니다. 전통적인 데이터베이스로는 저장·분석하기 어려웠지만, Databricks의 레이크하우스 아키텍처는 비정형 데이터를 정형 데이터와 같은 공간에 저장하고 AI/ML 모델로 분석할 수 있게 합니다.

고분자팀 관점에서 보면?

🏭 고분자제품기술팀 데이터 타입 분류
  • 정형 데이터: PP·PE·EAA 필름 물성 측정값 테이블 (인장강도, 신율, 헤이즈, 용융지수 등 수치 데이터), ERP 생산 이력 데이터
  • 반정형 데이터: 시험 성적서 JSON 파일, 고객사 기술 요청서 XML, 장비별 측정 로그 파일
  • 비정형 데이터: 필름 불량 부위 사진(이미지), 검사 보고서 PDF, 현미경 관찰 이미지, 고객사 클레임 이메일 본문

Databricks에서 각 타입을 다루는 방법

📊 정형·반정형 데이터 처리
  • Delta 테이블에 직접 적재
  • Spark SQL로 JOIN·집계 분석
  • Auto Loader로 JSON 자동 수집
  • 스키마 추론(inferSchema) 지원
🖼️ 비정형 데이터 처리
  • 이미지·PDF를 오브젝트 스토리지에 저장
  • 메타데이터는 Delta 테이블로 관리
  • MLflow + AI 모델로 내용 분석
  • Databricks AI Functions로 텍스트 추출

핵심 용어 카드

정형 데이터
행과 열로 구성된 테이블 형식. SQL로 바로 조회 가능. CSV, DB 테이블이 대표적
반정형 데이터
자체 구조 정보(키-값)를 갖지만 스키마가 고정되지 않은 데이터. JSON, XML이 대표적
비정형 데이터
정해진 구조 없는 데이터. 전체 데이터의 80% 이상. 이미지, PDF, 동영상이 해당
Auto Loader
Databricks에서 클라우드 스토리지의 새 파일을 자동으로 감지해 Delta 테이블에 적재하는 기능
스키마 추론
JSON 등 반정형 데이터의 구조를 자동으로 파악해 테이블 스키마를 생성하는 기능
📌 한 줄 요약
데이터는 정형(표) · 반정형(JSON) · 비정형(이미지·PDF)으로 나뉘며,
Databricks 레이크하우스는 세 가지 모두를 하나의 플랫폼에서 처리합니다.
오늘의 퀴즈
1다음 중 정형 데이터(Structured Data)에 해당하는 것은?
✅ 정답: ③
행과 열로 구성되고 스키마가 고정된 CSV 파일이 정형 데이터입니다. JPG·PDF는 비정형, JSON은 반정형 데이터에 해당합니다.
2반정형 데이터(Semi-structured Data)의 특징으로 가장 올바른 것은?
✅ 정답: ②
반정형 데이터는 JSON처럼 키-값 구조를 가지지만, 레코드마다 포함된 필드가 달라질 수 있어 고정 스키마가 없습니다. 이미지·동영상은 비정형 데이터입니다.
3세상에 존재하는 데이터 중 비정형 데이터가 차지하는 비율로 알려진 것은?
✅ 정답: ①
이미지, 동영상, 이메일, PDF 등 비정형 데이터는 전 세계 데이터의 80% 이상을 차지합니다. 이것이 레이크하우스 아키텍처가 비정형 데이터 처리를 중요하게 여기는 이유입니다.
4고분자팀에서 생성하는 다음 데이터 중 반정형 데이터에 해당하는 것은?
✅ 정답: ④
JSON 형식의 측정 로그는 키-값 구조를 가진 반정형 데이터입니다. DB 테이블은 정형, 현미경 이미지·PDF는 비정형 데이터에 해당합니다.
5Databricks에서 클라우드 스토리지에 새로 올라오는 JSON 파일을 자동으로 감지해 Delta 테이블에 적재하는 기능은?
✅ 정답: ③
Auto Loader는 S3·ADLS 같은 클라우드 오브젝트 스토리지를 모니터링하다가 새 파일이 추가되면 자동으로 읽어 Delta 테이블에 적재해주는 Databricks의 수집 기능입니다.
