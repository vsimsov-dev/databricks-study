Day 13 · Genie

Genie (Text to SQL) 개념과 활용

자연어로 데이터를 조회하는 새로운 방법

📅 2026년 6월 23일 ⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제
개념 설명

Genie란 무엇인가?

Databricks Genie는 자연어(한국어·영어 등 일상적인 언어)로 질문하면 자동으로 SQL 쿼리를 생성해 데이터를 조회해주는 기능입니다. SQL을 모르더라도 "이번 달 인장강도가 120MPa 이하인 PE 필름 목록 보여줘"처럼 말하듯이 입력하면 Genie가 SQL을 작성하고 결과를 표와 차트로 보여줍니다.

Databricks 플랫폼의 AI/BI 기능 중 하나로, 비개발자·현업 담당자도 데이터를 직접 조회할 수 있도록 데이터 접근성을 높이는 것이 목표입니다.

💡 핵심 한 줄: "SQL 몰라도 말로 데이터 조회하는 AI 어시스턴트"

Genie 사용 예시 — 대화형 데이터 조회

🧞 Genie 대화 예시 (고분자팀)
나
이번 달 인장강도가 120MPa 이하인 PE 필름 목록 보여줘
🧞
알겠습니다! 아래 쿼리로 조회했어요.
SELECT lot_id, grade, tensile_strength, test_date FROM silver.pe_film_properties WHERE test_date >= '2026-06-01' AND tensile_strength <= 120 ORDER BY tensile_strength ASC;
총 12건이 조회되었습니다. 표 또는 차트로 볼까요?
나
이 중에 신율이 400% 미만인 것만 다시 보여줘
🧞
조건을 추가해서 다시 조회했습니다.
SELECT lot_id, grade, tensile_strength, elongation, test_date FROM silver.pe_film_properties WHERE test_date >= '2026-06-01' AND tensile_strength <= 120 AND elongation < 400 ORDER BY tensile_strength ASC;
3건이 남았습니다.

Genie가 SQL을 생성하는 원리

1

테이블 스키마 파악

Genie는 연결된 테이블의 컬럼명, 타입, 설명(Comment)을 읽어 어떤 데이터가 있는지 이해합니다. Unity Catalog의 메타데이터가 핵심입니다.

2

자연어 의도 파악

입력된 자연어 문장을 대형 언어 모델(LLM)이 분석해 어떤 테이블의 어떤 컬럼을 어떤 조건으로 조회해야 하는지 파악합니다.

3

SQL 쿼리 생성

파악한 의도를 바탕으로 SQL 쿼리를 자동으로 작성합니다. 생성된 SQL은 사용자가 직접 확인하고 수정할 수 있습니다.

4

실행 및 결과 표시

SQL을 실행해 결과를 표, 막대그래프, 꺾은선 차트 등 적합한 형식으로 시각화합니다. 대화형으로 조건을 추가·수정할 수 있습니다.

Genie의 한계 — 알아야 할 주의사항

⚠️

복잡한 쿼리는 오류 가능

여러 테이블을 복잡하게 JOIN하거나 고급 윈도우 함수가 필요한 경우 잘못된 SQL을 생성할 수 있습니다. 항상 생성된 SQL을 검토하세요.

📋

컬럼 설명이 중요

Unity Catalog에 컬럼 설명(Comment)이 없으면 Genie가 컬럼 의미를 잘못 파악할 수 있습니다. 메타데이터 관리가 중요합니다.

🔒

데이터 접근 권한 필요

Genie도 Unity Catalog의 접근 권한을 따릅니다. 권한이 없는 테이블은 Genie로도 조회할 수 없습니다.

🔍

검증 필수

AI가 생성한 SQL이 의도와 다를 수 있습니다. 중요한 분석에는 생성된 쿼리를 반드시 검토·검증해야 합니다.

고분자팀에서 활용하는 방법

🏭 고분자제품기술팀 Genie 활용 예시
  • "이번 달 인장강도가 120MPa 이하인 PE 필름 목록 보여줘" — SQL 없이 불량 위험 로트 즉시 조회
  • "지난 3개월 동안 CPP 필름 헤이즈 평균이 가장 높았던 그레이드는?" — 품질 이슈 그레이드 빠르게 파악
  • "A 고객사에 납품한 PP 필름의 최근 6개월 물성 추이 보여줘" — 고객사별 품질 이력 즉시 확인
  • "신율 편차가 큰 로트 상위 10개 뽑아줘" — 공정 안정성 이상 징후 신속 탐지

오늘의 퀴즈
1Databricks Genie의 핵심 기능을 가장 올바르게 설명한 것은?
✅ 정답: ③
Genie(Text to SQL)는 "이번 달 인장강도가 120MPa 이하인 PE 필름 목록"처럼 자연어로 입력하면 SQL을 자동으로 생성해 데이터를 조회해주는 기능입니다. SQL을 모르는 현업 담당자도 활용할 수 있습니다.
2Genie가 자연어를 SQL로 변환하기 위해 가장 중요하게 참조하는 정보는?
✅ 정답: ①
Genie는 Unity Catalog에 등록된 테이블의 컬럼명, 데이터 타입, 컬럼 설명(Comment)을 읽어 어떤 데이터가 있는지 파악합니다. 메타데이터가 잘 정비되어 있을수록 Genie의 정확도가 높아집니다.
3Genie 사용 시 주의해야 할 한계점으로 옳지 않은 것은?
✅ 정답: ④
Genie도 Unity Catalog의 접근 권한을 동일하게 따릅니다. 권한이 없는 테이블은 Genie로도 조회할 수 없습니다. 권한 우회 수단이 아닙니다.
4고분자팀 담당자가 Genie에 "지난 3개월 동안 CPP 필름 헤이즈 평균이 가장 높았던 그레이드는?"이라고 질문했을 때 Genie가 하는 일의 순서로 올바른 것은?
✅ 정답: ②
Genie의 처리 순서는 테이블 스키마 파악 → 자연어 의도 파악 → SQL 쿼리 생성 → SQL 실행 → 결과 시각화 순서입니다. Unity Catalog 메타데이터를 먼저 읽어야 의미 있는 SQL을 생성할 수 있습니다.
5Genie 활용 시 정확도를 높이기 위한 가장 효과적인 방법은?
✅ 정답: ③
Genie는 Unity Catalog의 메타데이터(테이블·컬럼 설명)를 기반으로 데이터 의미를 파악합니다. 컬럼에 "인장강도(MPa) - PE 필름 MD 방향 측정값"처럼 명확한 설명을 등록할수록 Genie의 SQL 생성 정확도가 높아집니다.
