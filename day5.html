SQL로 데이터 조회하기

SELECT 기초부터 필터·집계·조인까지

⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제 🔄 복습: 4문제
오늘의 개념

엑셀에서 데이터를 찾을 때 필터 버튼을 클릭하거나 VLOOKUP 함수를 쓰셨나요? SQL은 그 모든 작업을 언어 한 줄로 해결합니다. "이 조건에 맞는 데이터를 저 테이블에서 꺼내와" 라고 말하면 되는 것이죠.

Databricks에서는 Notebook 셀에 SQL을 바로 입력하거나, Databricks SQL 워크스페이스에서 쿼리를 실행할 수 있습니다. Delta Lake 위에 쌓인 수백만 행 데이터도 몇 초 안에 원하는 결과만 뽑아낼 수 있어요.

① SELECT — "무엇을 보여줘?"

SQL의 가장 기본 문장입니다. SELECT 컬럼명 FROM 테이블명 구조를 기억하세요. 영어 문장처럼 "이 테이블에서 이 컬럼들을 선택해" 라고 읽으면 됩니다.

SQL 기본 SELECT
SELECT product_name, grade, melt_flow_index
FROM polymer_products
LIMIT 10;

▶ 결과 미리보기 (상위 3행)
SELECT→어떤 컬럼을 가져올지 (쉼표로 구분, * 는 전체)
FROM→어느 테이블에서 가져올지
WHERE→어떤 조건에 맞는 행만 (필터링)
GROUP BY→어떤 기준으로 묶을지 (집계)
ORDER BY→어떤 순서로 정렬할지

② WHERE — "이 조건에 맞는 것만 줘"

WHERE 절은 엑셀의 필터와 같습니다. 조건을 여러 개 걸 때는 AND / OR를 사용하고, 범위는 BETWEEN, 목록 비교는 IN을 씁니다.

SQL WHERE 필터링
SELECT product_name, melt_flow_index, tensile_strength
FROM polymer_products
WHERE grade = 'Premium'
AND melt_flow_index BETWEEN 1.5 AND 3.0
AND product_type IN ('CPP', '透明PP');
💡 팀에서는 이렇게 씁니다 고분자 제품 개발 업무에서 MFI(용융흐름지수), 인장강도, 열봉합 강도 등 물성 데이터를 테이블로 관리한다면, WHERE로 특정 그레이드나 물성 범위에 해당하는 제품만 바로 뽑아볼 수 있습니다. 엑셀에서 수동으로 필터 클릭하던 작업이 쿼리 한 줄로 끝납니다.

③ GROUP BY + 집계 함수 — "묶어서 요약해줘"

집계 함수는 여러 행을 하나의 요약값으로 만들어줍니다. GROUP BY로 그룹을 나누고, COUNT / SUM / AVG / MAX / MIN 등 집계 함수로 각 그룹의 통계를 냅니다.

함수역할예시
COUNT(*)행 개수제품 수 세기
AVG(col)평균값평균 MFI
SUM(col)합계총 생산량
MAX(col)최댓값최대 인장강도
MIN(col)최솟값최소 두께
SQL GROUP BY + 집계
-- 제품 타입별 평균 MFI와 제품 수 조회
SELECT product_type,
COUNT(*) AS product_count,
ROUND(AVG(melt_flow_index), 2) AS avg_mfi
FROM polymer_products
GROUP BY product_type
ORDER BY avg_mfi DESC;

④ JOIN — "두 테이블을 합쳐줘"

JOIN은 서로 다른 테이블을 공통 키(key)로 연결합니다. 마치 엑셀의 VLOOKUP처럼요. 가장 많이 쓰는 것은 INNER JOIN(둘 다 있는 것만)과 LEFT JOIN(왼쪽 테이블 기준)입니다.

🔵 INNER JOIN
두 테이블 모두에 존재하는 행만 반환. 가장 일반적.
🟢 LEFT JOIN
왼쪽 테이블 전체 + 오른쪽에 있으면 붙이고, 없으면 NULL.
🟣 RIGHT JOIN
오른쪽 테이블 전체 + 왼쪽에 있으면 붙이고, 없으면 NULL.
🟠 FULL OUTER JOIN
양쪽 모두 포함. 없는 쪽은 NULL로 채움.
SQL JOIN 예시
-- 제품 정보와 테스트 결과 테이블 합치기
SELECT p.product_name,
p.product_type,
t.test_date,
t.tensile_strength,
t.result
FROM polymer_products p
INNER JOIN quality_tests t
ON p.product_id = t.product_id
WHERE t.result = 'FAIL'
ORDER BY t.test_date DESC;

⑤ 실무 활용 예시

고분자 제품 개발 업무에서 SQL이 실제로 쓰일 수 있는 상황을 생각해볼게요. 레트로트용 CPP나 배터리 파우치용 소재처럼 물성 데이터가 많은 제품군은 테이블로 관리하면 효과적입니다.

📋 활용 시나리오: 지난 6개월간 레트로트 CPP 제품의 열봉합 강도 합격률을 제품 그레이드별로 비교하고 싶다면? — GROUP BY로 그레이드별 집계, WHERE로 기간 필터, JOIN으로 품질 테스트 테이블 연결하면 한 번에 가능합니다.
SELECT … FROM
SQL의 기본 구조. 테이블에서 원하는 컬럼을 선택한다.
WHERE
행(Row) 필터링 조건. 조건에 맞는 데이터만 반환.
GROUP BY
특정 컬럼 기준으로 행을 묶어 집계 함수와 함께 사용.
JOIN
공통 키로 두 테이블을 연결. INNER / LEFT가 가장 흔함.
HAVING
GROUP BY 이후 집계 결과에 조건을 거는 절. WHERE와 다름.
ALIAS (AS)
컬럼이나 테이블에 별명을 붙여 코드를 읽기 쉽게 만든다.
한 줄 요약
SQL은 SELECT(무엇을) → FROM(어디서) → WHERE(어떤 조건으로) → GROUP BY(어떻게 묶어서) 순서로 원하는 데이터를 언어처럼 꺼내는 도구입니다.
오늘의 퀴즈 — 5문제
1SQL에서 특정 조건에 맞는 행만 필터링할 때 사용하는 절은?
✅ 정답: ② — WHERE 절은 테이블에서 조건에 맞는 행만 반환합니다. HAVING은 GROUP BY 이후 집계 결과에 조건을 거는 데 사용합니다.
2다음 중 GROUP BY와 함께 사용하는 집계 함수가 아닌 것은?
✅ 정답: ③ — WHERE은 집계 함수가 아니라 필터링 절입니다. COUNT, AVG, MAX, MIN, SUM이 대표적인 집계 함수입니다.
3두 테이블에 모두 존재하는 행만 반환하는 JOIN 종류는?
✅ 정답: ① — INNER JOIN은 두 테이블에 공통으로 존재하는 행만 반환합니다. 가장 자주 사용하는 JOIN 유형입니다.
4SQL에서 결과 행 수를 상위 N개로 제한할 때 사용하는 절은?
✅ 정답: ④ — Databricks SQL(및 대부분의 현대 SQL)에서는 LIMIT N으로 반환 행 수를 제한합니다. 대용량 테이블 조회 시 LIMIT을 붙이는 습관이 중요합니다.
5SELECT 문에서 컬럼이나 테이블에 별명을 붙이는 키워드는?
✅ 정답: ② — AS 키워드로 컬럼이나 테이블에 별명(Alias)을 붙입니다. 예: SELECT AVG(mfi) AS avg_mfi

1Databricks Notebook에서 셀의 언어를 일시적으로 바꿀 때 사용하는 것은?

3반복적인 자동화 배치 작업에 적합하며, 작업 완료 후 자동으로 종료되는 클러스터 유형은?

4Notebook에서 파일 시스템을 조작하거나 셸 명령어를 실행할 때 사용하는 유틸리티는?
