Day 14 · AI Agent

AI 에이전트란?

스스로 계획하고 실행하는 AI 시스템

⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제 🔄 복습: 4문제
오늘의 핵심 개념

지금까지 배운 LLM, RAG, 벡터 DB는 모두 "질문하면 답한다"는 흐름이었습니다. 사용자가 묻고, AI가 문서를 찾아 답을 만들어주는 방식이죠. 그런데 실무에서는 답을 아는 것만으로 끝나지 않는 경우가 많습니다. "이 시험 데이터를 조회하고, 기준과 비교하고, 이상치가 있으면 보고서 초안까지 써줘"처럼 여러 단계를 스스로 이어서 처리해야 하는 일들이죠. 이런 다단계 작업을 사람의 개입 없이 스스로 계획하고 실행하는 AI 시스템을 AI 에이전트(AI Agent)라고 부릅니다.

오늘은 챗봇과 에이전트가 무엇이 다른지, 에이전트가 어떤 방식으로 "생각하고 행동"하는지, 그리고 고분자 제품기술팀 업무에 어떻게 적용할 수 있을지 살펴봅니다.

🤖 챗봇 vs 에이전트 — "답만 하는 사람" vs "직접 처리하는 사람"

비유하자면 챗봇은 전화 상담원과 비슷합니다. 질문하면 아는 선에서 답을 주지만, 그 이상의 행동은 하지 않습니다. 반면 AI 에이전트는 일 잘하는 비서에 가깝습니다. "다음 주 회의 준비해줘"라고 하면, 필요한 자료를 스스로 찾아보고, 일정을 확인하고, 초안까지 만들어 가져다줍니다. 즉 에이전트는 목표만 받으면 계획 → 도구 실행 → 결과 확인을 스스로 반복하며 일을 끝냅니다.

구분 일반 챗봇 / LLM AI 에이전트
동작 방식 ❌ 한 번 질문 → 한 번 답변 ✅ 목표 → 여러 단계를 스스로 계획·실행
외부 행동 ❌ 텍스트 답변만 생성 ✅ 도구(DB 조회, 계산, API 호출 등) 실제 실행
중간 판단 없음 결과를 보고 다음 행동을 스스로 결정
예시 "PP 열접착 강도 기준이 뭐야?" → 텍스트 답변 "이번 로트 시험 결과 기준 미달인지 확인하고 보고서 써줘" → 조회+비교+작성까지 수행

🔁 에이전트의 핵심 루프 — Plan → Act → Observe

AI 에이전트가 작동하는 기본 패턴은 "계획하고 → 행동하고 → 결과를 관찰해서 → 다시 계획한다"의 반복입니다. 이를 흔히 ReAct(Reasoning + Acting) 패턴이라 부릅니다. 사람이 요리할 때 "간을 보고(관찰) → 싱거우면 소금을 더 넣는(행동) 것"을 반복하는 것과 비슷합니다. 에이전트도 한 번의 행동으로 끝내지 않고, 결과를 확인한 뒤 필요하면 다음 행동을 다시 판단합니다.

AI 에이전트의 동작 루프
사용자 목표
→
계획 (Plan)
→
도구 실행 (Act)
→
결과 관찰 (Observe)
→
최종 답변

목표가 달성될 때까지 계획→실행→관찰을 반복합니다

🛠️ 도구 사용(Tool Use) — 에이전트의 "손과 발"

에이전트가 실제로 일을 처리하려면 텍스트 생성만으로는 부족합니다. 그래서 데이터 조회, 계산, 파일 검색, API 호출 같은 외부 기능("도구")을 함수 형태로 호출할 수 있어야 합니다. LLM이 "지금은 데이터베이스 조회 도구를 써야겠다"고 판단하면 해당 함수를 실행하고, 그 결과를 다시 LLM에 전달해 다음 판단에 활용합니다.

# AI 에이전트가 도구를 호출하는 개념 코드 (의사코드) def agent_loop(goal): plan = llm.think(goal) # 1. 계획 수립 while not plan.finished: action = llm.decide_next_action(plan) result = tools.call(action.tool_name, action.args) # 2. 도구 실행 plan = llm.update_plan(plan, result) # 3. 결과 관찰 & 재계획 return llm.final_answer(plan)

📶 자율성의 수준 — 어디까지 맡길 것인가

1

단순 응답형

질문 하나에 답 하나. 도구 없이 지식만으로 답변 (일반 챗봇 수준).

2

단일 도구 호출형

필요할 때 도구 하나를 호출해 정보를 가져온 뒤 답변 (예: DB 조회 후 답변).

3

다단계 자율 실행형

여러 도구를 순서대로 스스로 호출하며 목표를 달성할 때까지 반복 (진정한 의미의 "에이전트").

🧪 고분자 제품기술팀에서의 활용 예시

고분자 제품 개발 업무에서는 시험 데이터 조회, 규격 대조, 보고서 작성처럼 여러 단계를 거치는 반복 업무가 많습니다. AI 에이전트를 활용하면 "이번 주 CPP 열접착 강도 시험 결과를 불러와서 사내 기준과 비교하고, 기준 미달 건이 있으면 표로 정리해줘"처럼 한 번의 요청으로 조회·비교·정리까지 이어서 처리할 수 있습니다. 안전환경 업무에서는 "이번 달 신규 화학물질 MSDS를 확인하고, 유해성 분류가 이전과 달라졌으면 안전교육 자료 수정이 필요한 항목만 정리해줘"와 같은 다단계 작업에도 적용할 수 있습니다.

💡 실무 적용 아이디어

압출코팅 PP 라인의 일별 품질 데이터를 자동 조회하는 도구, 사내 규격 문서를 검색하는 도구, 보고서 초안을 작성하는 도구를 각각 만들어 에이전트에 연결하면, "오늘자 이상치 확인하고 보고서 초안 만들어줘" 한 마디로 전체 흐름을 자동화할 수 있습니다.

🔑 핵심 용어 카드

AI 에이전트
목표를 받으면 스스로 계획을 세우고 도구를 실행하며 작업을 끝까지 수행하는 AI 시스템.
ReAct 패턴
추론(Reasoning)과 행동(Acting)을 번갈아 반복하는 에이전트의 대표적인 동작 방식.
도구 사용(Tool Use)
에이전트가 DB 조회, 계산, API 호출 등 외부 기능을 함수 형태로 실행하는 것.
자율성 수준
단순 응답부터 다단계 자율 실행까지, 에이전트가 스스로 판단하는 범위의 정도.
오케스트레이션
여러 도구·모델 호출 순서를 조율해 하나의 목표로 이어지게 만드는 과정.
📌 한 줄 요약

AI 에이전트는 질문에 답만 하는 챗봇을 넘어, 목표를 받으면 계획→도구 실행→결과 관찰을 스스로 반복하며 일을 끝까지 처리하는 AI 시스템입니다.

오늘의 퀴즈 — 5문제
1AI 에이전트(AI Agent)를 가장 정확하게 설명한 것은?
✅ 정답: ② — AI 에이전트는 목표만 주어지면 스스로 계획을 세우고, 필요한 도구를 호출해 실행하며, 결과를 확인해 다음 행동을 판단하는 AI 시스템입니다.
2에이전트의 동작 루프(Plan → Act → Observe)에서 'Act' 단계가 의미하는 것은?
✅ 정답: ② — Act 단계는 에이전트가 실제로 도구(데이터 조회, 계산, API 호출 등)를 호출해 작업을 수행하는 단계입니다. 이후 Observe 단계에서 그 결과를 관찰합니다.
3AI 에이전트가 '도구(Tool)'를 사용한다는 것은 구체적으로 무엇을 의미하나요?
✅ 정답: ② — 도구 사용은 에이전트가 검색, 계산기, DB 조회, API 호출 같은 외부 기능을 함수 형태로 직접 실행해 실질적인 작업을 처리하는 것을 말합니다.
4에이전트의 자율성 수준이 높아질수록 나타나는 특징은?
✅ 정답: ① — 자율성 수준이 높아질수록 에이전트는 단순 응답을 넘어, 사람의 추가 개입 없이 여러 단계를 스스로 판단하고 이어서 실행할 수 있습니다.
5고분자 제품기술팀 실무에 AI 에이전트를 적용한다면 가장 적절한 활용 예시는?
✅ 정답: ① — AI 에이전트의 강점은 조회·비교·작성처럼 여러 단계를 하나의 목표 아래 자동으로 이어서 처리할 수 있다는 점입니다. 고분자 시험·규격 비교 업무에 특히 적합합니다.
🔄 어제 배운 내용 복습 — Genie (Text to SQL) 개념과 활용
1Databricks Genie의 핵심 기능으로 가장 알맞은 것은?
✅ 정답: ① — Genie는 사용자가 자연어로 질문하면 이를 SQL 쿼리로 자동 변환해 데이터를 조회해주는 Text-to-SQL 도구입니다.
2Genie가 더 정확한 답변을 하도록 도와주는 요소는?
✅ 정답: ① — Genie는 테이블·컬럼에 대한 설명과 샘플 질문 같은 컨텍스트를 등록해둘수록 자연어 질문을 더 정확한 SQL로 변환합니다.
3Genie는 주로 누구를 위해 설계된 도구인가요?
✅ 정답: ② — Genie는 SQL 문법을 몰라도 자연어로 질문해 데이터를 탐색할 수 있도록, 현업·비즈니스 사용자를 위해 설계된 도구입니다.
4Genie는 Databricks의 어떤 제품 영역에 속하나요?
✅ 정답: ① — Genie는 Databricks AI/BI 제품군에 속하며, 자연어 기반 데이터 조회와 분석을 지원합니다.
