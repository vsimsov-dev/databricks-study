Day 15 · MCP

MCP (Model Context Protocol) 개념

AI 에이전트와 외부 도구를 연결하는 표준 프로토콜

📅 2026년 6월 25일 ⏱ 학습 시간: 약 10분 📝 퀴즈: 5문제
개념 설명

MCP란 무엇인가?

AI가 점점 똑똑해지고 있지만, 혼자 할 수 있는 일은 제한적입니다. 회사 ERP 시스템의 데이터를 가져오거나, 사내 데이터베이스를 조회하거나, 이메일을 발송하려면 AI가 외부 도구와 대화할 수 있어야 합니다. 그런데 지금까지는 각 AI 시스템마다 연동 방식이 달라 개발 비용이 컸습니다.

MCP(Model Context Protocol)는 Anthropic이 제안한 AI 에이전트와 외부 도구·데이터를 연결하는 표준 프로토콜입니다. USB 규격처럼, MCP를 지원하면 어떤 AI 클라이언트와 어떤 서버든 공통 방식으로 연결할 수 있습니다. 2024년 말 오픈소스로 공개된 이후 빠르게 생태계가 확장되고 있습니다.

💡 MCP를 한 마디로 표현하면: "AI 에이전트를 위한 USB 표준 규격". 한 번 만들면 어디서든 꽂아 쓸 수 있습니다.

왜 MCP가 필요한가?

기존 방식에서는 AI를 CRM 시스템에 연결하려면 별도의 커스텀 통합 코드가 필요했고, 다른 AI로 바꾸면 처음부터 다시 개발해야 했습니다. MCP는 이 문제를 표준화로 해결합니다.

🔌

표준화된 연결

MCP를 지원하는 AI라면 MCP Server에 바로 연결됩니다. 커스텀 통합 코드가 필요 없습니다.

♻️

재사용 가능

한 번 만든 MCP Server는 Claude, GPT 등 여러 AI에서 재사용할 수 있습니다.

🔒

보안 경계 명확

어떤 도구에 어떤 권한을 줄지 서버 단에서 명시적으로 정의합니다.

🌐

오픈 생태계

GitHub, Slack, 데이터베이스 등 수백 개의 MCP Server가 이미 공개되어 있습니다.

MCP Server / Client 구조

MCP는 Host(AI 애플리케이션), Client(프로토콜 처리 레이어), Server(외부 도구 제공자) 세 가지로 구성됩니다.

🤖 AI 클라이언트 (Claude Desktop, IDE 등)
MCP Client를 내장한 호스트 애플리케이션
⇅ MCP 프로토콜 (JSON-RPC)
🗄️ MCP Server
ERP 연동
🔬 MCP Server
물성 DB 조회
📧 MCP Server
이메일 발송

MCP Server는 세 가지 기능을 제공합니다: Tools(AI가 실행할 수 있는 함수), Resources(읽을 수 있는 데이터), Prompts(재사용 가능한 프롬프트 템플릿). AI는 필요한 기능을 MCP Server에 요청하고 결과를 받아 처리합니다.

Databricks에서의 MCP 활용

Databricks는 2025년부터 AI/BI Genie, Unity Catalog, DBRX 등의 기능을 MCP Server로 노출하기 시작했습니다. 이를 통해 개발자가 Claude나 다른 AI 도구에서 직접 Databricks 데이터를 조회하거나, Delta Lake 테이블을 탐색하거나, Spark 잡을 실행할 수 있게 됩니다. 기업 데이터를 AI 에이전트와 안전하게 연결하는 인프라 역할을 MCP가 담당하는 것입니다.

🏭 고분자팀 실제 활용 시나리오 영업팀으로부터 "CPP 필름 물성 규격 자료 보내줘"라는 요청이 오면, AI 에이전트가 MCP를 통해 ① 사내 ERP에서 고객 정보 조회 → ② 물성 DB에서 해당 제품 스펙 조회 → ③ 조회된 데이터로 기술지원 보고서 자동 생성 → ④ 이메일 초안 작성까지 한 번에 처리할 수 있습니다. 각 시스템에 MCP Server 하나씩만 만들면 됩니다.

핵심 용어 카드

MCP
Model Context Protocol. AI 에이전트와 외부 도구·데이터를 연결하는 Anthropic 표준 프로토콜
MCP Server
특정 도구나 데이터 소스(ERP, DB 등)의 기능을 MCP 규격으로 노출하는 서버
MCP Client
AI 애플리케이션 안에서 MCP Server와 통신을 처리하는 레이어
Tools
MCP Server가 AI에게 제공하는 실행 가능한 함수 (예: 데이터 조회, 이메일 발송)
Resources
MCP Server가 AI에게 제공하는 읽기 전용 데이터 (예: 파일, DB 레코드)

오늘의 퀴즈
1MCP(Model Context Protocol)의 핵심 역할은 무엇인가요?
✅ 정답: ③
MCP는 AI 에이전트가 ERP, 데이터베이스, 이메일 등 외부 시스템과 표준화된 방식으로 연결할 수 있게 해주는 프로토콜입니다. AI 모델 학습이나 SQL 최적화와는 관계가 없습니다.
2MCP를 "USB 표준 규격"에 비유하는 이유로 가장 적절한 것은?
✅ 정답: ②
USB처럼 표준화된 규격이기 때문에, MCP Server를 한 번 만들면 Claude, GPT 등 MCP를 지원하는 어떤 AI에서도 재사용할 수 있습니다. 이것이 커스텀 통합 대비 핵심 장점입니다.
3MCP Server가 AI 클라이언트에게 제공하는 세 가지 기능이 올바르게 나열된 것은?
✅ 정답: ①
MCP Server는 Tools(AI가 실행할 수 있는 함수), Resources(읽을 수 있는 데이터), Prompts(재사용 가능한 프롬프트 템플릿) 세 가지 기능 유형을 AI 클라이언트에게 제공합니다.
4고분자팀에서 MCP를 활용해 기술지원 보고서를 자동 생성할 때, AI 에이전트가 순서대로 수행하는 작업은?
✅ 정답: ④
영업 요청이 오면 AI가 MCP를 통해 ① ERP에서 고객 정보 조회 → ② 물성 DB에서 제품 스펙 조회 → ③ 보고서 자동 생성 → ④ 이메일 초안 작성 순서로 처리합니다. 데이터를 먼저 수집한 뒤 문서를 작성하는 흐름입니다.
5Databricks가 MCP Server를 제공하면 어떤 이점이 생기나요?
✅ 정답: ②
Databricks가 Unity Catalog, AI/BI Genie 등의 기능을 MCP Server로 노출하면, Claude 같은 AI 클라이언트에서 직접 Databricks 데이터 조회, Delta Lake 테이블 탐색, Spark 잡 실행 등을 수행할 수 있습니다.
